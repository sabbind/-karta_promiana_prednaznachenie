# Регистър на решенията на Комисията за земеделските земи (КЗЗ)

Отворен регистър на решенията на КЗЗ за промяна на предназначението на земеделски земи и свързаните с тях
действия (утвърждаване на площадки и трасета, временно ползване, изменение и отмяна на решения),
извлечен автоматично от публикуваните решения на сайта на МЗХ:
https://www.mzh.government.bg/bg/uslugi/komisiya-za-zemedelskite-zemi/resheniya-komisiyata-zemedelskite-zemi/

## Файлове

- `data/register.csv` – цялата страна, по един ред за всеки имот във всяка точка на решение
- `data/register_sofia.csv` – само Столична община
- `data/decisions.csv` – списък на решенията
- `data/text/` – текстът на всяко решение
- `out/report.json` – статистика; `out/run.log` – лог от последното пускане

Колони: решение, дата, точка, действие, идентификатор, ЕКАТТЕ, проектни идентификатори, част от имот,
вече построено, площ (кв. м), категория, поливна/неполивна, обект, населено място, местност, район, община, област, УПИ,
препратки към други решения, линк към документа.

**Собственици не се извличат** (нито имена, нито инициали).

## Обновяване

GitHub Actions пуска агента всеки месец на 5-о число (`.github/workflows/update.yml`); ръчно – Actions → Run workflow.
